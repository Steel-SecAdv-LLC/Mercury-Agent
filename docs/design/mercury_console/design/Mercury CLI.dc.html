♱ CAPTURESKeep the sections of data that matterA capture is a range of samples from a result or from your loaded file. It keeps the rows, scores and flags, statistics for each column, the request that produced them and a SHA-256 of the data, so the section can be cited, shared and checked later.

                  

                    
INCIDENT WINDOWA flagged event with samples of context before and after it. CAPTURE ALL FLAGGED EVENTS saves every event in one step.

                    
BASELINEA clean stretch tagged NORMAL, kept to compare incidents against.

                    
REVIEW · EVIDENCEQuestionable flags for a second look, and sections you need to cite in a report.

                  

                  
WHERE CAPTURES GOEach capture exports as CSV or JSON. ANOMALY captures build a 0/1 labels file for tier-detect, train, tune and build-features (-l). The evidence pack puts every capture, labels file and recording in one ZIP with SHA256SUMS.

                  

                  From the terminal: :capture 120 180 anomaly pump trip · :rec · :mark valve opened · :rec stop
                

              
              
                

                  
♱ RECORDINGSRecord a working sessionA recording keeps every command, output line, result, capture, mark and agent message with the time it happened. Marks are your own notes on the timeline, added from the bar at the top while recording.

                  
EXPORTS.cast plays back with asciinema play · .md is a lab notebook of the session · .json keeps every event · replay .sh re-runs the session's commands in order.
